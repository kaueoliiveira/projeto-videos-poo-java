
Este projeto foi desenvolvido durante meus estudos de Java com o objetivo
de aprofundar os conceitos de Programação Orientada a Objetos.

A aplicação simula uma plataforma de vídeos, permitindo a interação entre
usuários e vídeos por meio de visualizações, avaliações e controle de conteúdo.

Durante o desenvolvimento foram aplicados conceitos importantes como herança, polimorfismo, encapsulamento, construtores e relacionamento
entre classes.

Este projeto foi criado para consolidar conhecimentos de Programação Orientada a Objetos
e praticar a modelagem de objetos utilizando Java.
